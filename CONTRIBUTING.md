# Contributing to Qrisp

Thank you for your interest in contributing to Qrisp! Whether you are fixing a
bug, improving the documentation, adding a new feature, or writing a tutorial,
all contributions are welcome.

Please read the [Qrisp Development Guide](https://qrisp.eu/reference/Development%20Guide/index.html)
in the documentation. It covers setting up your development environment, code
quality standards, writing tests, the pull request workflow, and more.

If you have questions, join the community on [Discord](https://discord.gg/v5np7DeBaq).

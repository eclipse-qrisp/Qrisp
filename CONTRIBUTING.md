# Contributing to Eclipse Qrisp

Thank you for your interest in contributing to **Eclipse Qrisp**, an open-source Python framework for high-level quantum programming and quantum algorithm development.

## Project resources

- Website: [qrisp.eu](https://www.qrisp.eu/)
- Documentation: [Qrisp documentation](https://www.qrisp.eu/reference/)
- Full contribution guide: [Qrisp Development Guide](https://www.qrisp.eu/reference/Development%20Guide/index.html)
- Downloads: [Qrisp on PyPI](https://pypi.org/project/qrisp/)
- Canonical source code: [eclipse-qrisp GitHub organization](https://github.com/eclipse-qrisp) and the primary [Qrisp repository](https://github.com/eclipse-qrisp/Qrisp)

## Communication

Our primary community communication channel is [Discord](https://discord.gg/v5np7DeBaq).
For bug reports, feature requests, and project-specific questions, please use the [Qrisp GitHub issue tracker](https://github.com/eclipse-qrisp/Qrisp/issues).

## How to contribute

1. For non-trivial changes, please open an issue first to discuss the proposal with the maintainers. Small fixes, such as typo or broken-link fixes, may be submitted directly.
2. Sign the [Eclipse Contributor Agreement (ECA)](https://www.eclipse.org/legal/ECA.php) before submitting a contribution.
3. Fork the [Qrisp repository](https://github.com/eclipse-qrisp/Qrisp), create a focused branch, and implement your change.
4. Add or update tests and documentation where appropriate. Run the relevant test suite before submitting your change.
5. Open a focused pull request against the canonical Qrisp repository. Clearly describe the motivation, implementation, tests, and any potential breaking changes.

Please follow the detailed setup, testing, code-quality, documentation, and pull-request guidance in the [Qrisp Development Guide](https://www.qrisp.eu/reference/Development%20Guide/index.html).
